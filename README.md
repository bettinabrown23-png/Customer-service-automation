# Customer-service-automation
A simple customer service workflow project demonstrating how automation can improve customer follow- ups and support.
## How I Created This Project

I created this project to demonstrate a simple customer follow-up automation workflow using Python.

### Process
1. Identified customers who required follow-up.
2. Created a list of customers and their current status.
3. Used Python to check each customer's status.
4. The program automatically identifies customers who need follow-up and displays them for action.

### Example
Customers marked as needs_follow_up are automatically identified by the program, while resolved customers are skipped.

### Purpose
This project demonstrates basic workflow automation, conditional logic, and how automation can help improve customer follow-up and support.
